2 · 需求规格说明书

2.1 范围与非目标

类别内容
目标具备中断权限的登录用户，可在警报详情对 STATUS=Process 的警报执行强制中断：必填原因 + 二次确认；中断后状态 Terminated、当前层级关闭、待发通知 Skipped、调度不再升级/失败重送/推进 ACK；写入 TRX_TYPE=AlarmTerminate 交易（操作人/时间/原因）；AVPA007 可查，AVPA013/004 口径可区分。
非目标不撤销中断；不批量中断；不审批流；不新增通知渠道；不改造既有权限模型（仅用户主档布尔字段）；不改 ACK 语义与升级/重送配置结构；不新增数据库表；历史交易详情保持只读。
非功能原子性（状态/层级/通知/交易同一事务）、并发仅一次成功、服务端鉴权为唯一边界、无外部调用、失败整体回滚、现有三种状态行为回归不变。

2.2 需求条目

REQ-001P0用户主档（SBRM_USER）新增「警报强制中断权限」CAN_TERMINATE（Y/N，默认 N），随新增/修改/Excel 导入导出/隐藏恢复保存；服务端以最新主档为唯一授权依据。未填写→N；改 N 后下一次请求即拒绝（无需重登）；停用/隐藏/缺字段一律拒绝且零写入。

REQ-003P0新增 POST /api/alarms/:key/terminate，body {cmt}，返回 {ok,alarm,terminated}；按 存在(404)→Process(400)→权限(400)→原因(400) 顺序校验。原因 trim 后非空且 ≤500；重复/非 Process 400「该警报已非处理中状态」；并发仅 1 次成功、仅 1 条交易；未登录 401。

REQ-005P0详情主资讯工具区「强制中断」（danger）+ 二次确认 Modal（标题、目标识别码/标题、不可逆风险、必填原因 500 字计数、取消/确认中断、错误区）；成功后刷新详情、提示「警报已中断」、通知外层刷新；Terminated 显示中断横幅。非 Process 禁用并说明；无权限禁用并说明；历史只读无按钮；提交中 loading 不可重复提交；失败保留弹窗与原因。
REQ-006P1中断信息展示与报表口径：AVPA007 按 TRX_TYPE=AlarmTerminate / STATUS=Terminated 可查；AVPA004 状态支持 Terminated 且 COMPLETE_DT 有值；AVPA013 仅统计 Process；options.alarmStatus 追加 Terminated。既有 Process/Completed/NoNextLevel 查询结果不变。
REQ-007P2功能树新增「警报强制中断作业」（ALARM_LIST，FUNC_TYPE=PAGE），列表为 Process 警报（PRIORITY 降序），点开进入详情。遵循 ACTIVE/VISIBLE；无权限账号无可用中断操作，服务端仍拒绝越权。

4.1 后端：AlarmEngine.canTerminate()（权限判定）

/** Authorization is always read from the current user master; the session copy is not trusted. */
private boolean canTerminate(Map<String, Object> user) {
    if (user == null) return false;
    var master = store.find("users","USER_KEY",user.get("USER_KEY"));
    return master != null && active(master) && eq(master,"CAN_TERMINATE","Y");
}

4.2 后端：AlarmEngine.terminate()（原子收敛）

public Map<String, Object> terminate(String key, Map<String, Object> body, Map<String, Object> user) {
    var alarm = store.table("alarms").stream().filter(r -> eq(r,"ALARM_KEY",key) || eq(r,"ALARM_ID",key)).findFirst()
        .orElseThrow(() -> new ApiException(404,"警报不存在"));
    require(eq(alarm,"STATUS","Process"),"该警报已非处理中状态");
    require(canTerminate(user),"您没有强制中断权限");
    String cmt = s(body,"cmt").trim();
    require(!cmt.isEmpty(),"请填写中断原因");
    require(cmt.length() <= COMMENT_MAX,"中断原因不可超过 "+COMMENT_MAX+" 个字符");
    String at = now();
    close(alarm,"Terminated","AlarmTerminate",user,cmt,
        m("TERMINATE_DT",at,"TERMINATE_CMT",cmt,"TERMINATE_USER_KEY",user.get("USER_KEY")));
    // Only pending deliveries are cancelled; already sent or failed history stays intact.
    related("alarm_notifications",alarm.get("ALARM_KEY")).stream().filter(r -> eq(r,"RESULT","Pending")).forEach(r -> {
        r.put("RESULT","Skipped"); r.put("MESSAGE","警报已中断，取消发送");
        if (s(r,"SEND_DT").isBlank()) r.put("SEND_DT",at);
    });
    return m("ok",true,"alarm",enrich(alarm,user),"terminated",true);
}
